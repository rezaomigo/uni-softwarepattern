# سامانه پاسخگویی هوشمند به پرسش‌های دانشگاهی
## تمرین درس طراحی الگوهای نرم‌افزار پیشرفته — مقطع دکتری تخصصی مهندسی کامپیوتر

این پروژه یک پلتفرم تحلیل، شبیه‌سازی و ارزیابی معماری الگوهای نرم‌افزار برای **«سامانه پاسخگویی به پرسش‌های دانشجویان درباره آیین‌نامه‌ها، دروس، مقررات آموزشی و خدمات دانشگاه با استفاده از منابع معتبر»** است.

---

### الگوهای سه‌گانه پیاده‌سازی و بررسی شده:
1. **Model Gateway (درگاه مدیریت و تجرید مدل‌ها):** مسیریابی پویا، کش معنایی پرسش‌های متداول، کلید مدار شکن (Circuit Breaker) و سوئیچ به سرورهای محلی دانشگاه.
2. **RAG (تولید افزوده با بازیابی دانش):** بازیابی هیبریدی (ترکیب وکتوری HNSW و واژگانی BM25)، بازرتبه‌بندی Cross-Encoder و استناد دقیق کلمه‌به‌کلمه به شماره مواد آیین‌نامه‌ها.
3. **Planning (عامل برنامه‌ریزی ReAct):** تجزیه مسائل چندبخشی، استدلال گام‌به‌گام (Thought-Action-Observation) و اتصال به وب‌سرویس‌های آموزشی گلستان با محافظ‌های قطعی مهار حلقه.

---

### بخش‌های پیاده‌سازی شده در سامانه:
* **فاز اول و دوم:** سایدبار تعاملی با عناوین انگلیسی و باز شدن زیرمجموعه‌های پنج‌گانه برای هر الگو (معرفی الگو، طراحی معماری، اجرای سناریو، تحلیل تصمیم طراحی، ارزیابی معماری).
* **فاز سوم:** انطباق عمیق محتوا با استعلام‌های واقعی دانشگاهی (مشروطی، سقف واحد، سنوات، مرخصی و...).
* **فاز چهارم:** تحلیل‌های ۶ گانه دکتری با دکمه‌های مجزا (دلیل انتخاب، تعامل میان الگوها، سناریوی شکست، معیارهای کیفیت ISO 25010، تمایز رفتار واقعی/شبیه‌سازی/هوش مصنوعی، و مراجع علمی معتبر).
* **فاز پنجم:** پنجره تعاملی «نمودار معماری سامانه» در هدر (شامل لایه‌ها، مؤلفه‌ها و جریان متوالی داده).
* **فاز ششم:** پنجره «گزارش تحلیلی» ۵ صفحه‌ای قابل مطالعه و چاپ با فرمت PDF.
* **فاز هفتم:** بیانیه شفاف‌سازی دانشگاهی درباره نقش هوش مصنوعی و اصلاحات اصیل دانشجو.

### راهنمای اجرای سریع پروژه (Quick Start Guide):

#### پیش‌نیازها:
* نصب بودن **Node.js** (نسخه ۱۸ به بالا)

#### گام ۱: نصب وابستگی‌ها
در ترمینال، وارد پوشه پروژه شده و دستور زیر را اجرا نمایید:
```bash
npm install
```

#### گام ۲: اجرای محیط توسعه (Development Server)
```bash
npm run dev
```
سپس آدرس محلی زیر را در مرورگر باز کنید:
```
http://localhost:3000
```

#### گام ۳: اجرای تست‌های اعتبارسنجی معماری
جهت اطمینان از صحت اعتبارسنجی شاخص‌های معماری:
```bash
npm test
```

#### گام ۴: بیلد نهایی نسخه Production
```bash
npm run build
```
فایل‌های خروجی مستقل در پوشه `dist/` قرار می‌گیرند و به کمک مسیرهای نسبی (`./`) در هر وب‌سروری قابل اجرا هستند.
